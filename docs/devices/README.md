# Device profiles

What kiln found on each device it has been run on: the hardware as the system reports it, what
kiln chose, and what was measured. Written down so that work on core selection, GPU backends or
thermals can be reasoned about without having the device in hand.

- [Galaxy S26 Ultra](galaxy-s26-ultra.md): Snapdragon 8 Elite Gen 5 (SM8850), 2 + 6 cores with no little cores, Adreno 840.

The Pixel 8 (Tensor G3) is described in [../CPU.md](../CPU.md) and [../bench](../bench/README.md).
